# SA Study — システムアーキテクト試験 学習アプリ

IPA「システムアーキテクト試験（SA）」対策の個人用学習アプリです。ビルド不要の静的 Web アプリで、学習記録はブラウザ内（localStorage）に保存されます。

## 使い方

- **ローカル**：`index.html` をブラウザで開くだけ（オフラインで動作）
- **スマホでも使う**：GitHub Pages（Settings → Pages → Branch を選択）で公開し、ホーム画面に追加（PWA 対応・オフライン可）
- 端末を変えるときは「設定 → バックアップを書き出す／読み込む」

## モード

| モード | 内容 |
|---|---|
| 今日の学習 | 復習期限の問題＋新しい問題を分野が偏らないよう混ぜて毎日15問（問題数は設定で変更可） |
| 復習 | 間隔反復で復習期限が来た問題 |
| 本番模試 | 2026年度 CBT 方式準拠。科目A群の日（A-1→A-2）／科目B群の日（B-1→B-2）／科目別／ミニ模試（A-2 10問16分）。多段階選抜の判定つき |
| 分野別演習 | 分野・問題数・対象（未学習／間違えた／ブックマーク）・順序（混ぜる／まとめる）を指定 |
| 弱点克服 | 正答率が低い・何度も忘れた問題 |
| 直前総仕上げ | 試験日時点の推定記憶保持率が低い問題から |
| 記述（B-1）演習 | 1事例45分。字数カウンタ付き入力 → 模範解答・キーワード照合 → 自己採点 |
| 論述（B-2）演習 | 120分。骨子メモ → 設問ア・イ・ウを字数カウンタ付きで論述 → IPA の評価観点に沿って自己評価（参考ランク） |
| 問題一覧 | 検索・状態フィルタ・ブックマーク・自分のメモ |

| 科目 | 時間 | 形式 | 問題数 |
|---|---|---|---|
| 科目A-1 | 50分 | 四肢択一 | 30問 |
| 科目A-2 | 40分 | 四肢択一 | 25問 |
| 科目B-1 | 90分 | 記述式 | 3問中2問 |
| 科目B-2 | 120分 | 論述式 | 2問中1問 |

## 取り入れた学習法

- **間隔反復**（SM-2 系）：問題ごとに次回の復習日を計算。同じ日の解き直しや期日前の復習では間隔を伸ばしすぎない。復習待ちが多いときは新規を止める。間隔21日以上で「定着」
- **想起練習（テスト効果）**：読むより解く。模試の解答も復習スケジュールに反映
- **自信度評価（メタ認知）**：自信あり／たぶん／勘 で復習間隔を調整。自信ありの誤答を強調（過剰修正効果）
- **インターリーブ**：分野を交互に出題
- **即時フィードバック＋精緻化**：誤答の理由まで含む解説、自分の言葉でメモ、誤答はセッション内で再出題
- **本番を模した練習**：本番と同じ時間・問題数・字数制限
- **可視化**：学習曲線、忘却曲線の予測（べき関数モデル）、復習予定、分野別正答率、自信度キャリブレーション、学習カレンダー、初見正答率、収録問題の想起率（本番の得点予測ではない）

詳しくはアプリ内の「学習法」ページを参照してください。

## 収録問題

すべてオリジナルの練習問題です（IPA 過去問の転載ではありません）。

- 科目A-1：72問（9分野）
- 科目A-2：120問（10分野）
- 科目B-1：9事例
- 科目B-2：12テーマ

選択肢は正解だけが長くならないようにそろえています（最長の選択肢＝正解の割合は約25%）。問題の追加は `data/SCHEMA.md` の形式で `data/*.js` に追記し、新しいファイルを作った場合は `index.html` と `sw.js` に追加してください。
