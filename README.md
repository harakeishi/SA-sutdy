# SA Study — システムアーキテクト試験 学習アプリ

IPA「システムアーキテクト試験（SA）」対策の個人用学習アプリです。ビルド不要の静的 Web アプリで、学習記録はブラウザ内（localStorage）に保存されます。

## 使い方

- **ローカル**：`index.html` をブラウザで開くだけ（オフラインで動作）
- **スマホでも使う**：GitHub Pages（Settings → Pages → Branch を選択）で公開し、ホーム画面に追加（PWA 対応・オフライン可）
- 端末を変えるときは「設定 → バックアップを書き出す／読み込む」

## モード

| モード | 内容 |
|---|---|
| 今日の学習 | 復習期限の問題＋新しい問題を分野が偏らないよう混ぜて毎日15問（問題数は設定で変更可） |
| 復習 | 間隔反復で復習期限が来た問題 |
| 本番模試 | 2026年度 CBT 方式準拠。科目A群の日（A-1→A-2）／科目B群の日（B-1→B-2）／科目別／ミニ模試（A-2 10問16分）。多段階選抜の判定つき |
| 分野別演習 | 分野・問題数・難易度・対象（未学習／間違えた／ブックマーク）・順序（混ぜる／まとめる）を指定 |
| 弱点克服 | 正答率が低い・何度も忘れた問題 |
| 直前総仕上げ | 試験日時点の推定記憶保持率が低い問題から |
| 記述（B-1）演習 | 1事例45分。字数カウンタ付き入力 → 模範解答・キーワード照合 → 自己採点 |
| 論述（B-2）演習 | 120分。骨子メモ → 設問ア・イ・ウを字数カウンタ付きで論述 → IPA の評価観点に沿って自己評価（参考ランク） |
| 問題一覧 | 検索・状態フィルタ・ブックマーク・自分のメモ |

| 科目 | 時間 | 形式 | 問題数 |
|---|---|---|---|
| 科目A-1 | 50分 | 四肢択一 | 30問 |
| 科目A-2 | 40分 | 四肢択一 | 25問 |
| 科目B-1 | 90分 | 記述式 | 3問中2問 |
| 科目B-2 | 120分 | 論述式 | 2問中1問 |

## スマホ向け UI/UX

- **ボトムタブバー**（ホーム／演習／模試／分析／設定）：親指の届く画面下部に主要ナビゲーション
- **集中モード**：演習・模試中はナビを隠し、上部に進捗バーと×、下部の固定バーに解答ボタン（自信度・次へ・前後移動）
- **スワイプ**：解説画面で左スワイプ→次へ、模試で左右スワイプ→前後の問題
- **ボトムシート**：模試の問題一覧（解答済・見直しマーク）と提出
- **記述式（B-1）**：スマホでは「問題文／設問・解答欄」をセグメントで切替
- **フィードバック**：正解・不正解のマイクロアニメーション、振動（Android）、今日のノルマ達成時の紙吹雪、進捗リング
- **すりガラス調のバー**、セーフエリア（ノッチ・ホームインジケータ）対応、タップ領域 44〜56px、入力欄 16px 以上（iOS の自動ズーム防止）
- **設定**：テーマ（自動／ライト／ダーク）、文字サイズ（4段階）、振動・演出のオン／オフ。OS の「視差効果を減らす」に従いアニメーションを停止
- **PWA**：ホーム画面アイコン（iOS 用・maskable）、ショートカット（今日の学習・本番模試）、オフライン動作

## 取り入れた学習法

- **間隔反復**（SM-2 系）：問題ごとに次回の復習日を計算。同じ日の解き直しや期日前の復習では間隔を伸ばしすぎない。復習待ちが多いときは新規を止める。間隔21日以上で「定着」
- **想起練習（テスト効果）**：読むより解く。模試の解答も復習スケジュールに反映
- **自信度評価（メタ認知）**：自信あり／たぶん／勘 で復習間隔を調整。自信ありの誤答を強調（過剰修正効果）
- **インターリーブ**：分野を交互に出題
- **即時フィードバック＋精緻化**：誤答の理由まで含む解説、自分の言葉でメモ、誤答はセッション内で再出題
- **本番を模した練習**：本番と同じ時間・問題数・字数制限
- **可視化**：学習曲線、忘却曲線の予測（べき関数モデル）、復習予定、分野別正答率、自信度キャリブレーション、学習カレンダー、初見正答率、収録問題の想起率（本番の得点予測ではない）

詳しくはアプリ内の「学習法」ページを参照してください。

## 収録問題

### オリジナル問題
- 科目A-1：122問（9分野。うちマネジメント22問、ストラテジ28問、難問★★★28問）
- 科目A-2：163問（10分野。うちストラテジ28問、難問★★★37問）
- 科目B-1：9事例
- 科目B-2：12テーマ

### IPA 過去問（出典明記）
| 区分 | 年度 | 収録 |
|---|---|---|
| 午前Ⅰ（科目A-1相当） | 令和6・7年度 春期・秋期 | 4回分 120問 |
| 午前Ⅱ（科目A-2相当） | 令和3〜7年度 春期 | 5回分 125問 |
| 午後Ⅰ（科目B-1相当） | 令和5〜7年度 春期 | 10事例（IPA 解答例・採点講評付き） |
| 午後Ⅱ（科目B-2相当） | 令和3〜7年度 春期 | 13テーマ（出題趣旨・採点講評付き） |

- IPA は公表済みの過去問題について、教育目的など制度の趣旨に反しない利用では許諾・使用料は不要とし、出典（年度・期・試験区分・時間区分・問番号）の明記を求めています（[IPA よくある質問](https://www.ipa.go.jp/shiken/faq.html)）。各問に出典を表示しています。
- 正解・解答例・出題趣旨・採点講評は IPA 公表のもの、**解説・骨子例は本アプリ独自**です。
- 「模試」タブの「IPA 過去問（年度別）」で、当時と同じ問題数・制限時間で1回分を解けます。通常の演習や「今日の学習」にも混ぜて出題します（設定で切替）。
- 年度をまたいで再出題された問題は、通常出題では新しい年度の1問だけを出します。現行の規格・法令で前提が変わった問題は通常出題から外す仕組みがあります（現時点で該当なし。補足は解説に記載）。
- 下付き文字の表記（Q_X など）や表のテキスト化など、表示のための最小限の変更をした箇所は問題内に注記しています。

選択肢の長さや数値の大小から正解が推測できないよう、正解の長さ順位・大小順位がほぼ均等になるようにしています（`node tools/check-bank.js` で形式チェックと偏りの集計ができます）。分野別演習では難易度（★〜★★★）で絞り込めます。問題の追加は `data/SCHEMA.md` の形式で `data/*.js` に追記し、新しいファイルを作った場合は `index.html` と `sw.js` に追加してください。

```
index.html
css/style.css
js/srs.js      間隔反復エンジン・忘却曲線
js/charts.js   SVG チャート
tools/check-bank.js  問題データの検査（形式・手がかりの偏り・過去問の出典と図）
data/past/     IPA 過去問
past/img/      過去問の図表画像
js/app.js      画面・模試・統計
data/          問題データ
sw.js, manifest.webmanifest  PWA
```
