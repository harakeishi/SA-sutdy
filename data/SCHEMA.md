# 問題データ形式

すべて `data/*.js` に置く素の JavaScript（ビルド不要、`file://` でも動くように JSON ではなく JS）。
問題は IPA の過去問を丸写しせず、シラバスと出題傾向に沿った**オリジナル問題**として作成する。

## 科目A（四肢択一）: `window.QB.a1` / `window.QB.a2`

```js
window.QB = window.QB || {};
window.QB.a2 = (window.QB.a2 || []).concat([
  {
    id: "a2-p1-001",          // 一意。ファイルごとに接頭辞を変える
    cat: "信頼性・性能",       // 下記カテゴリ一覧のいずれか（完全一致）
    q: "問題文。改行は \n。",
    choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"], // ア〜エの記号は付けない
    answer: 2,                // 正解の 0 始まりインデックス
    exp: "解説。正解の根拠と、各誤答がなぜ誤りか。計算問題は途中式も。",
    level: 2,                 // 1=基本 2=標準 3=難
    noShuffle: false          // 「すべて」「ア及びイ」など並び順に依存する場合だけ true
  },
]);
```

アプリは選択肢をシャッフルして表示するので、選択肢の文中で「ア」「イ」などの記号を参照しないこと（参照する場合は `noShuffle: true`）。

## 科目B-1（記述式）: `window.QB.b1`

```js
window.QB.b1 = (window.QB.b1 || []).concat([
  {
    id: "b1-01",
    title: "〇〇システムの再構築",
    cat: "情報システム" ,        // "情報システム" または "組込み・IoT"
    scenario: "問題文本文（数千字程度でよい）。段落は \n\n、表は簡易テキストで。",
    questions: [
      {
        no: "設問1(1)",
        q: "設問文",
        limit: 30,              // 字数制限（字以内）。制限なしの場合 0
        answer: "模範解答",
        keywords: ["採点で重視するキーワード", "..."],
        exp: "解答の考え方。本文のどこが根拠か。"
      }
    ]
  }
]);
```

## 科目B-2（論述式）: `window.QB.b2`

```js
window.QB.b2 = (window.QB.b2 || []).concat([
  {
    id: "b2-01",
    title: "〇〇について",
    cat: "情報システム",          // "情報システム" または "組込み・IoT"
    body: "問題文の前文（背景・論点の説明）",
    parts: [
      { no: "ア", q: "設問ア", min: 0,   max: 800 },
      { no: "イ", q: "設問イ", min: 800, max: 1600 },
      { no: "ウ", q: "設問ウ", min: 600, max: 1200 }
    ],
    points: ["論述で押さえるべきポイント", "..."],
    outline: "骨子（章立て）の例。\n1. ...\n 1.1 ..."
  }
]);
```
