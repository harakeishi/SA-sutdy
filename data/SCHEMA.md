# 問題データ形式

すべて `data/*.js` に置く素の JavaScript（ビルド不要、`file://` でも動くように JSON ではなく JS）。
問題は IPA の過去問を丸写しせず、シラバスと出題傾向に沿った**オリジナル問題**として作成する。

## 科目A（四肢択一）: `window.QB.a1` / `window.QB.a2`

```js
window.QB = window.QB || {};
window.QB.a2 = (window.QB.a2 || []).concat([
  {
    id: "a2-p1-001",          // 一意。ファイルごとに接頭辞を変える
    cat: "信頼性・性能",       // 下記カテゴリ一覧のいずれか（完全一致）
    q: "問題文。改行は \n。",
    choices: ["選択肢1", "選択肢2", "選択肢3", "選択肢4"], // ア〜エの記号は付けない
    answer: 2,                // 正解の 0 始まりインデックス
    exp: "解説。正解の根拠と、各誤答がなぜ誤りか。計算問題は途中式も。",
    level: 2,                 // 1=基本 2=標準 3=難
    noShuffle: false          // 「すべて」「ア及びイ」など並び順に依存する場合だけ true
  },
]);
```

アプリは選択肢をシャッフルして表示するので、選択肢の文中で「ア」「イ」などの記号を参照しないこと（参照する場合は `noShuffle: true`）。

## 科目B-1（記述式）: `window.QB.b1`

```js
window.QB.b1 = (window.QB.b1 || []).concat([
  {
    id: "b1-01",
    title: "〇〇システムの再構築",
    cat: "情報システム" ,        // "情報システム" または "組込み・IoT"
    scenario: "問題文本文（数千字程度でよい）。段落は \n\n、表は簡易テキストで。",
    questions: [
      {
        no: "設問1(1)",
        q: "設問文",
        limit: 30,              // 字数制限（字以内）。制限なしの場合 0
        answer: "模範解答",
        keywords: ["採点で重視するキーワード", "..."],
        exp: "解答の考え方。本文のどこが根拠か。"
      }
    ]
  }
]);
```

## 科目B-2（論述式）: `window.QB.b2`

```js
window.QB.b2 = (window.QB.b2 || []).concat([
  {
    id: "b2-01",
    title: "〇〇について",
    cat: "情報システム",          // "情報システム" または "組込み・IoT"
    body: "問題文の前文（背景・論点の説明）",
    parts: [
      { no: "ア", q: "設問ア", min: 0,   max: 800 },
      { no: "イ", q: "設問イ", min: 800, max: 1600 },
      { no: "ウ", q: "設問ウ", min: 600, max: 1200 }
    ],
    points: ["論述で押さえるべきポイント", "..."],
    outline: "骨子（章立て）の例。\n1. ...\n 1.1 ..."
  }
]);
```

# IPA 過去問（data/past/*.js）

IPA は公表済みの過去問題について、教育目的など制度の趣旨に反しない利用であれば許諾・使用料を不要としている。
その条件として**出典（年度・期・試験区分・時間区分・問番号）を明記**し、**改変した場合はその旨を明記**する。
問題文・選択肢は原文どおり（明らかな表記ゆれの統一のみ）。解説 `exp` は IPA が公表していないため本アプリ独自に作成し、その旨を画面に表示する。

## 午前Ⅰ・午前Ⅱ（四肢択一）

```js
window.QB = window.QB || {};
window.QB.a2 = (window.QB.a2 || []).concat([   // 午前Ⅰは window.QB.a1
  {
    id: "p-2025r07h-am2-01",      // p-<年度期>-<am1|am2>-<問番号2桁>
    set: "2025r07h-am2",          // 年度別模試の単位
    no: 1,                        // 問番号
    src: "令和7年度 春期 システムアーキテクト試験 午前Ⅱ 問1",   // 出典（午前Ⅰは「高度試験共通 午前Ⅰ」）
    cat: "設計・モデリング",       // オリジナル問題と同じカテゴリ名
    q: "問題文（原文どおり）",
    choices: ["ア の文", "イ の文", "ウ の文", "エ の文"],  // 原文の順。記号は付けない
    answer: 3,                    // IPA 解答例どおり（ア=0 … エ=3）
    noShuffle: true,              // 過去問は原文の順で出す
    exp: "独自の解説。正解の根拠と各選択肢の説明。",
    level: 2,
    fig: "past/img/2025r07h-am2-01.png",   // 図表が必要な場合のみ。問題文中の図表・選択肢の図
    figAlt: "図の内容の文字による説明",
    choicesInFig: false,          // 選択肢そのものが図の中にある場合 true（choices は ["ア","イ","ウ","エ"]）
    obsolete: ""                  // 現行の規格・法令・用語では通用しない場合に理由を書く（通常出題から除外）
  }
]);
```

## 午後Ⅰ（記述式）→ `window.QB.b1`

オリジナル問題の B-1 形式に加えて `id: "p-2025r07h-pm1-1"`, `set`, `no`, `src`, `figs`（`{"図1": "past/img/...png"}`、本文中は `[[図1]]` で参照）, `review`（IPA 採点講評の該当問の要旨、出典付き）。
各設問の `answer` は IPA 解答例を原文どおり（複数の解答例は「／」で併記）。`exp` は独自の考え方。

## 午後Ⅱ（論述式）→ `window.QB.b2`

オリジナル問題の B-2 形式に加えて `id: "p-2025r07h-pm2-1"`, `set`, `no`, `src`, `intent`（IPA 公表の出題趣旨。原文どおり）, `review`（IPA 採点講評の該当問。原文どおり）。`points` と `outline` は独自作成。
